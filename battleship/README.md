# Battleship для Cotonti

Современный плагин «Морской бой» для CMS/CMF [Cotonti](https://www.cotonti.com).

Играйте против компьютера или в PvP с другими авторизованными пользователями. Классические правила, аккуратный интерфейс на Bootstrap 5.3, понятная разметка поля и живые уведомления.

---

## Возможности

- **Режимы игры**
  - Против компьютера (AI)
  - PvP — создание открытой игры и присоединение к существующей

- **Интерфейс**
  - Два отдельных поля: «Ваш флот» и «Поле противника»
  - Координаты **A–J** / **1–10**
  - Легенда с цветными обозначениями клеток
  - Toast-уведомления с разными фразами («Попал!», «Мимо!», «Потопил!» и т.д.)
  - Адаптивная вёрстка под Bootstrap 5.3

- **Расстановка кораблей**
  - Ручная расстановка с превью
  - Случайная расстановка
  - Поворот корабля
  - Очистка поля
  - Счётчик оставшихся кораблей

- **Игровая механика**
  - Классический состав флота: 1×4, 2×3, 3×2, 4×1
  - Корабли не касаются друг друга (включая диагонали)
  - Определение потопления
  - Статистика игроков (победы / поражения / рейтинг)
  - Возможность сдаться

## Требования

- Cotonti (актуальная ветка)
- PHP 8.1+ (рекомендуется 8.5)
- MySQL / MariaDB
- Bootstrap 5.3 на сайте (для корректного отображения)

---

## Установка

1. Скопируйте папку `battleship` в директорию `plugins/` вашего сайта.
2. Зайдите в **Админку → Расширения**.
3. Найдите плагин **Battleship** и установите его.
4. При необходимости настройте параметр «Максимум активных игр на пользователя».

После установки игра будет доступна по адресу:

```
index.php?e=battleship
```

(или через ЧПУ, если настроено).

## Как играть

1. Авторизуйтесь на сайте.
2. Откройте страницу плагина.
3. Выберите режим:
   - **Против компьютера** — сразу переходите к расстановке.
   - **Создать PvP-игру** — ждёте соперника.
   - **Открытые игры** — присоединяетесь к существующей.
4. Расставьте корабли (или нажмите «Случайно») и подтвердите.
5. Стреляйте по полю противника. Следите за уведомлениями и легендой.

---

## Технические детали

- Все действия идут через AJAX (`battleship.ajax.php`).
- Состояние игры хранится в таблицах:
  - `cot_battleship_games`
  - `cot_battleship_stats`
- CSRF-защита через стандартный `x`-токен Cotonti.
- AI использует простой hunt-режим (после попадания бьёт соседние клетки).
